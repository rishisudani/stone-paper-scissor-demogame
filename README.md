# 🪨 Stone Paper Scissor Game

A simple browser-based Stone Paper Scissor game made with JavaScript. The player competes against the computer.

## 🚀 Features
- Interactive UI for user choice.
- Random computer move generator.
- Score tracking for both sides.
- Result messages with each round.

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript (Randomization, DOM updates)

## ⚙️ How to Play
1. Clone this repository:
   ```bash
   git clone https://github.com/rishisudani/stone-paper-scissor-demogame.git
   ```
2. Open `index.html` in your browser.
